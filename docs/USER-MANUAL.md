# 玩家安装与使用

[English](USER-MANUAL.en.md)

HollowKnightTAS Studio 用来录制、编辑和回放《空洞骑士》的逐帧输入。界面包含输入编辑器、时间线、操作手册、信息显示、Boss 状态机和设置六页，支持中文与 English。

## 安装与启动

需要 Windows x64、《空洞骑士》和已安装的 Modding API。使用完整的 HollowKnightTAS 发布包，保留配套工具的目录结构。Studio 发布包自带 .NET 运行时和 FFmpeg 视频编码器。

1. 保存编辑并关闭游戏和 Studio。
2. 将包解压到游戏的 `hollow_knight_Data/Managed/Mods/HollowKnightTAS`。若压缩包已有顶层 `HollowKnightTAS` 文件夹，则解压到 `Mods`。避免形成双层同名目录。
3. 确认该目录直接包含 `HollowKnightTAS.dll`、`HollowKnightTAS.Core.dll`、`companion.manifest.json` 和 `Companion/win-x64/HollowKnightTAS.Companion.exe`。更新时使用同一发布包中的完整配套文件。
4. 启动游戏，在标题画面的「选项 → Modding → HollowKnightTAS」选择「打开 Studio（重启游戏）」。等待受控游戏停在启动第 0 帧。

普通启动游戏时，TAS 控制、录制、外部接口、碰撞箱和信息显示保持未激活。

其他 Mod 可以一起启用，兼容性由使用者确认。回放会核对实际运行环境，包括游戏及 Mod 身份、画面等设置；环境不匹配时应使用匹配环境重新运行。

QoL、DebugMod、GodSeekerPlus、Benchwarp、SpeedRunQoL 和 Custom Knight 的禁用及功能关闭清单，见[TAS 辅助 Mod 兼容清单](HELPER-MOD-COMPATIBILITY.md)。

## 游戏信息显示

Studio 的「信息显示」页默认开启画面叠加：Movie 帧、房间内部名、坐标、速度、普通冲刺与暗影冲刺冷却、生命和灵魂。Runtime 连接后显示，播放与单步时更新，暂停时保留；角色不可用或加载中显示 `—`。冷却的「就绪」只表示计时结束，其他动作限制仍然有效。

可搜索添加字段、删除或勾选隐藏条目，拖动排序或使用上移／下移。选中条目后可修改表达式、显示名称、小数位（0–6）、单位和颜色，预设字段同样可编辑；名称或颜色留空使用默认值。颜色写作 `#RRGGBB`。设置自动保存，可恢复默认；「恢复预设表达式」只恢复当前条目的表达式。

面板默认贴近游戏画面右上角，支持四角定位、X/Y 边距、字号和背景透明度；拖动游戏窗口期间保持相对位置。勾选「调整位置」后直接拖动画面中的面板，完成后取消勾选以恢复鼠标穿透。F11 默认切换显示，可改为 F12 或关闭快捷键；游戏内快捷键需启用全局热键。

「将已勾选的信息条目录入 MP4」默认关闭。开启后，v2 序列视频按导出开始时的条目、表达式和外观设置逐帧合成信息；桌面上的显隐开关独立生效。导出期间修改设置只影响下次导出，窗口遮挡不会录入视频。

### RT 和 GT

搜索并添加 `RT` 或 `GT` 预设，默认以秒显示。RT 从序列输入就绪的零点开始，包含加载帧，等于完整序列视频的累计时长；GT 使用 Hollow Knight LiveSplit 的加载排除规则累计同样的帧时长。TAS 编辑暂停不累计；游戏自己的暂停菜单是否累计遵循 LiveSplit 规则。

表达式 `rt - 12.5` 将序列第 12.5 秒作为显示零点；GT 同理可写 `gt - 12.5`。允许负值；要限制为零以上可写 `rt < 12.5 ? 0 : rt - 12.5`。区间视频保留序列计时起点，若需从零显示，可减去区间起点对应的 RT/GT。计时值表示当前完成帧的末端；不自动套用 LiveSplit 的开跑或结束分段设置。

### 自定义只读信息

点击「添加自定义字段」，或选中已有预设，在「只读表达式」中编辑，然后设置显示名称、精度等。字段名区分大小写。支持 `+ - * / %`、括号、比较、`&& || !`、`条件 ? 值 : 值`，以及双引号文字拼接。例如 `health / maxHealth * 100`。原预设未改动时保留其特殊格式；修改表达式后按结果类型和条目精度显示。

输入时会提示常用字段候选；Ctrl+空格打开候选，↑↓选择，Enter/Tab 插入，Esc 关闭。补全只替换光标所在字段，不覆盖整条表达式。候选包含预设标量及常用已知字段，并非所有游戏对象的字段枚举。

可用根对象：`hero`（小骑士）、`player`（PlayerData）、`game`（GameManager）、`position` 和 `velocity`（小骑士位置/速度）。

| 查询 | 含义 |
| --- | --- |
| `hero.dashCooldownTimer` | 普通冲刺原始冷却计时器 |
| `hero.cState.wallSliding` | 是否正在滑墙 |
| `player.geo` | 吉欧数量 |
| `player.equippedCharms[0]` | 已装备护符列表第一项；空列表不可用 |
| `position.x` | 小骑士 X 坐标 |
| `component("/Knight", "HeroController").jump_steps` | 指定对象组件的字段 |
| `fsm("/Knight", "Spell Control", "MP Cost")` | 指定 FSM 的变量 |

组件查询支持游戏及其他 Mod 的实例字段，类型名可用完整命名空间。对象路径必须以 `/` 开头，使用实际激活对象的完整层级路径；存在多个同类组件时明确报错。FSM 名和变量名须精确匹配。字段可串联，数组与 `List<T>` 可用从0开始的下标。

查询直接读取公开/私有字段及自动属性的 backing field，末端支持数字、布尔、字符串和枚举；不运行方法、普通属性 getter、赋值或任意 C# 脚本。原始计时器保留真实值（可能为负），预设冷却行才会显示「就绪」。字段或对象不存在时，该行显示 `—`，页底说明原因，其他行继续显示。最多32行、每条查询512字符、16级字段。

## Boss 状态机

打开「Boss状态机」页，选择当前场景中的 Boss，再点击「添加本体及子对象」。每个 PlayMaker FSM 显示为一张独立状态图，当前状态以亮色标出。左侧可搜索并勾选其他对象的 FSM，例如独立的场景控制器；实例编号用于区分同名对象，未激活的模板有单独标识。

滚轮缩放，按住左键拖动图形；「适应」显示全图，「定位当前状态」将当前节点移入视野。可搜索状态、折叠图卡或放大单图。点击节点查看已加载动作的类型。普通转移和全局转移保留游戏中的事件名。

最多同时选择 32 个 FSM。暂停观察不会推进游戏；单步和播放后刷新高亮，页面底部显示采样帧。快速经过的中间状态可能未被采样。重建后只自动重新绑定路径和名称均唯一的目标；同名歧义时重新选择。离开页面停止查询。纯 C# 或协程控制的行为需要单独适配。

## 开始录制或回放

在输入编辑器打开 `.hktaspack` 序列包，然后播放或步进。未打开序列时，播放或步进会开始新录制。录制包含菜单和游戏操作；游戏加载期间推进原生循环，但不消耗 Movie 输入帧。

顶部「播放/暂停」切换运行状态，「步进」推进一帧；继续播放快捷键 P 只在暂停时继续。Frame N 表示输入区间 `[0,N)` 已执行，下一步执行第 N 行。Native frame 是原生循环计数，不能直接当作表格行号。

默认快捷键：

| 操作 | 按键 |
| --- | --- |
| 播放/暂停 | Pause |
| 继续播放 | P |
| 步进，按住连续步进 | V |
| 打开 / 保存序列 | Ctrl+O / Ctrl+S |
| 复制 / 粘贴 | Ctrl+C / Ctrl+V |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 插入 / 删除帧 | Insert / Delete |
| 恢复快捷槽 | F1–F10 |
| 保存快捷槽 | Shift+F1–F10 |

在设置页可以修改控制快捷键。启用「全局热键」后，游戏或其他窗口获得焦点时，播放、暂停、继续、步进和快捷槽仍可使用；文件及表格编辑快捷键只在 Studio 内生效。注册冲突会显示在设置页。文本框内优先输入文字。

## 编辑输入

每行对应一帧，动作列头显示游戏绑定的按键，悬停可查看动作名。单击按键格切换输入，按住鼠标上下拖动可编辑同一列的一段输入。Shift 选择连续帧，Ctrl 选择不连续帧；右键菜单可复制、粘贴、插入、删除及修改选区帧率。滚到末尾后继续向下滚动可追加空帧。

未来输入在下一次播放或步进前自动同步。修改已经执行过的输入后，选中目标行并点击「回放到当前帧」，让游戏按修改后的序列恢复到所选行；按钮中的“当前帧”指表格选中帧。「播放时跟随」默认勾选；勾选后，表格随实际执行位置滚动；取消后可停留在任意浏览位置。

默认帧率为 50，范围为 1–1000，支持最多 6 位小数，例如 99.999。设置页的默认帧率只影响新建和追加帧；已有帧通过右键「修改选区帧率…」修改。游戏鼠标开关用于新序列，已开始的序列沿用记录的鼠标模式。启用游戏鼠标后，录制与回放必须保持相同分辨率。

选区帧率决定这些帧的时间长度，并用于游戏执行与视频导出。例如，100 FPS 下的 100 帧为 1 秒；切换帧率从选区第一帧生效。修改已执行帧的帧率后，也需要回放到目标帧以恢复相应进度。

在「插入帧数」中填写正整数，再点「插入空帧」，可从选区起点一次插入多个空帧，右键插入共用该数量；一次撤销会撤回整批插入。

双击 `RNG 种子` 单元格，或右键选择「修改当前帧 RNG 种子…」，可设置该 Movie 帧开始前使用的种子。接受 -2147483648 至 2147483647 的整数，`0` 有效，留空清除。每个设置只在对应帧开始前执行一次，后续随机数自然演进；场景切换仍沿用场景 RNG 重置规则。种子随帧复制、插入和删除，支持撤销重做；修改已执行帧与修改按键一样会产生世界线分叉，并需重放。

## 自定义按键

在输入编辑器第一排「删除帧」右侧选择按键，再点击「添加自定义键」，然后在新增列中逐帧勾选或拖动编辑。连续勾选表示按住，先留一帧松开才能再次触发按下；组合键分别添加并同帧勾选。配置和输入随序列保存，支持撤销重做。「移除自定义键」删除整个序列中的该键及其输入。添加或移除后需重新应用／回放。

自定义键用于其它 Mod 的键盘快捷键，与 Studio 播放、步进快捷键分开配置。支持通过 Unity GetKey、GetKeyDown、GetKeyUp 读取的按键，其它输入方式需确认兼容性。若与 Studio 全局热键冲突，可在设置中调整或关闭全局热键。

## 保存序列和初始存档

Ctrl+S 或「保存序列」首次选择文件路径，之后覆盖当前文件；「保存序列到...」选择新路径。新建序列使用 `.hktaspack`，包含完整输入以及启动第 0 帧固定的四槽初始存档快照，包括空槽和槽位关联的 Mod 文件。分享序列包即可携带这些初始条件。

手动保存、保存到新路径及自动保存保留同一份初始快照，不采集录制后的游戏进度。播放、重播、回档及视频导出从包内快照建立独立影子存档，受控游戏中的存取档只改变影子副本。存档绑定不能替代运行环境兼容性校验。

点击「编辑存档」，选择文件后直接编辑 JSON 文本。「保存修改到序列」会保留原时间线，并为修改后的初始存档建立新起点；随后点击「保存序列」另存为新的序列包。JSON 格式错误时会保留编辑内容并提示修正。

「导出存档…」将当前副本中的所有存档及 Mod 附属文件导出到所选位置下的新文件夹，保留游戏存档格式，不覆盖已有文件。

`.hktas` 文本序列显示「未绑定初始存档」，依赖本机起始存档；保存时仍使用该格式。包损坏或初始存档缺失时会拒绝加载。

默认序列目录为 Windows 文档目录下的 `HollowKnightTAS/Sequences`。自动保存按现实时间每 300 秒（5 分钟）检查一次，将有变化的完整草稿写入该目录的 `Autosave` 子目录，不覆盖手动保存的文件，也不推进游戏。设置页可修改目录和间隔，0 表示关闭，最大 86400 秒；已有设置继续生效。

## 时间线与回档

时间线保存不同输入分支及恢复节点。分支叶子记录实际运行到的最远帧，同时保留完整未来输入。点击叶子加载该分支，选择节点并执行「恢复所选节点」才改变游戏位置。恢复祖先节点后仍保留所选分支的后续输入。

「保存当前帧为节点」、表格右键保存及 Shift+F1–F10 记录恢复目标，不播放或回档到目标。运行中保存会先暂停。未来帧或修改后尚未验证的目标标记为「未验证存档」，不计入实际最远进度。F1–F10 执行恢复；时间线中可将现有节点绑定到快捷槽。

右键未来帧可播放到该帧并暂停；过去帧可恢复到该帧并暂停，不必事先创建节点。回档通过受保护重启和输入重放完成，需要等待。期间游戏画面、表格与选区保持静止，禁止编辑，进度条按已重放帧数与目标帧数更新；完成后显示目标结果，失败则解除冻结并提示原因。

时间线、检查点和 F1–F10 快捷槽绑定只保留在本次 Studio 会话的内存中；重新打开 Studio 后清空，游戏回档重启不清空。需要跨会话保留输入时，请保存序列文件。序列文件和 `Autosave` 副本继续保留。删除节点及子树前会要求确认。

中途打开文件会先校验文件，再暂停并保存原分支；加载失败保留当前序列。成功切换后，播放从新序列起点开始，也可重算到选中行。关闭前请用 Ctrl+S 保存需要保留的序列。正常关闭会结束正在进行的视频导出、处理当前分支并退出 Studio 持有的受控游戏；这些操作不会替代手动保存序列文件。关闭处理失败时窗口保留并提示。退出后本次时间线与快捷槽绑定清空，未保存到文件或 Autosave 的编辑可能丢失。

旧序列可打开、编辑和回放。执行规则与当前版本不同会提示兼容性差异，部分输入帧可能需要调整。手动保存更新文件中的执行规则标识，保留输入、按键配置和初始存档；自动保存保留原标识。

## 导出 MP4

选择一个尚不存在的 `.mp4` 输出路径，Studio 会使用内置编码器。

- 输入编辑器的 MP4 按钮导出当前完整序列，包括未来草稿输入。
- 时间线中设置起点和终点，导出同一祖先路径上的区间 `(起点帧,终点帧]`。反向选择自动排序，兄弟分支之间不能直接导出。

导出会自动恢复并回放；准备阶段不录入视频，正式采集期间的加载画面会录入，所以视频帧数可能多于 Movie 输入帧数。暂停后可继续同一次采集，取消准备或采集不发布最终 MP4。以导出状态完成为准，不以请求返回或临时文件出现为准。

## 设置与故障处理

设置页可以选择语言、帧率、鼠标模式、序列保存目录、自动保存间隔、快捷键和碰撞箱显示。碰撞箱默认关闭，只显示轮廓，不改变游戏碰撞判定。

- Studio 未连接：确认通过 TAS 启动入口启动，等待 Runtime 就绪；普通游戏会话不提供 TAS 控制。
- 配套文件校验失败：重新安装完整的同一发布包，保留目录结构。
- 序列环境不匹配：恢复录制时的游戏、Mod 和画面设置。不要通过修改环境指纹跳过校验。
- 回档或导出失败：保留错误信息并检查当前操作状态，避免重复提交。
- 反馈问题：在设置页底部点击“导出诊断日志”，选择目录后将 ZIP 连同复现步骤和帧号发送给维护者。包含 Studio 自身的应用日志及保留的历史运行日志；Studio 日志副本与耗时历史保留 7 天、合计最多 256 MiB。

AI 和脚本接口见 [AI 控制指南](AI-CONTROL.md)。
